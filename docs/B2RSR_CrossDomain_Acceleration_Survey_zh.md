## 0. 一页速览：本次调研最重要的三个发现

### 发现 1：LLM 侧的 speculative decoding 给出了"带保证的加速"范式，但不能直接照搬

`draft-then-verify` 是全领域**唯一有数学证明的无损加速**（修正拒绝采样，
Leviathan ICML 2023 / Chen 2023）。但它便宜的根本原因是**自回归串行性**——
大模型一次并行前向可验证 γ 个 token。**SR 是单次密集预测，让大网"验证"全图
= 让大网跑一遍全图，加速恒等于 0**。可迁移的是它的设计哲学而非算法：

> 用便宜计算决定昂贵计算花在哪，且用**显式、可调的验收准则**控制输出偏差。

其中 **LayerSkip（ACL 2024）是最有参考价值的范本**：训练时 layer dropout 让浅层
出口可用，推理时用 self-speculative 验证把早退的近似性"洗回"无损，实测 1.82–2.16×。

### 发现 2：动态计算拿不到真实加速有明确的定量规律，我们的失败完全符合

`dynamic_nn.md` 给出了权威答案，与本项目三轮失败一一对应：

| 粒度 | GPU 能否兑现 | 定量证据 | 对应我们的经历 |
|---|---|---|---|
| **像素级空间稀疏** | ❌ 无专用 kernel 时为负 | DynConv 需自写 CUDA kernel，仍远低于理论值 | — |
| **8×8 独立窗口** | ❌ | — | v1：0.844×（慢 18%） |
| **block/patch 级（S=4/8）** | ✅ | SBNet 2.3×、LASNet 1.56–1.85×、LAUDNet >2× | 主线 α 的正确粒度 |
| **整层跳过** | ✅（少发 kernel，无 gather/scatter） | LAUDNet 证实 | v2 深度扫描延迟完美线性 ✓ |
| 2:4 半结构化 | ⚠️ 1.3–1.8×（理论 2×） | PyTorch 官方 A100 GEMM 1.39× | 未测 |
| 非结构化稀疏 | ❌ ≈1× | 需 bitmap+定制 kernel 才 ≤1.58× | — |

**关键机制解释**：kernel launch 开销 5–15 µs/次（NVIDIA 官方），batch=1 时数百个
小 kernel 使推理 launch-bound；路由决策的 GPU→CPU 同步每次数十 µs 并打断流水；
gather/scatter 本身 memory-bound。**我们 RCAN 一次前向 >800 个 kernel、
实测 fp16 反而更慢，正是 launch-bound 的教科书症状。**

必要条件清单（8 条，见 `dynamic_nn.md` §7 Q2）中最关键的三条：粗且规则的粒度、
以延迟（而非 FLOPs）为目标函数、保持静态化优化（CUDA Graphs / 算子融合）可用。

### 发现 3【最重要】：存在一个被三方独立报告共同指向的空白

三份报告从不同角度指向同一处空白：

- `dynamic_nn.md`：**回归型自适应计算的质量保证完全空白**。两块拼图已存在——
  Fast yet Safe（NeurIPS 2024）的 conformal risk control 早退框架、
  Adame et al.（NeurIPS 2025）的 conformal-PSNR 控制——**但从未被组合**；
  空间/区域粒度的风险控制亦无先例。
- `llm_inference.md`：SR 加速研究几乎全在"纯近似"一端；把**统计校准保证**
  引入 SR 空间自适应加速是识别出的最具新颖性的迁移机会。
- `sr_efficiency_2026.md`（穷尽查新）：「独立异构快慢模型级联 + **输出后验校验**
  + 统计质量保证（± LUT 快路径）」的完整组合**无人占据**；
  机制级新颖性**高**，组合级**中等偏高**。

## 2. 领域现状：2025–2026 高效 SR 的三条主线

来自 `sr_efficiency_2026.md`，三年 NTIRE runtime 赛道趋势明确：

1. **配方化极轻 CNN**（统治者）：SPAN 骨干 + 重参数化 + 蒸馏 + LoRA-merge。
   NTIRE 2024 冠军 XiaomiMM（SPAN 系）、2025 冠军 **DSCLoRA**（SJTU，
   LoRA 低秩分支合并进 SPAN 卷积，零推理开销）、ESPAN（GRep+自蒸馏+渐进训练）。
   **趋势判读**：架构创新空间已很小，竞争转向训练配方与部署工程（TensorRT/半精度/算子融合）。
2. **LUT 家族**：SR-LUT→MuLUT→RC-LUT→HKLUT（IJCAI 2024，百 KB）→
   **TinyLUT（NeurIPS 2024，树莓派上比 FSRCNN 快 5×，存储仅 MuLUT 4.1%）**→
   AutoLUT（CVPR 2025）→IM-LUT（ICCV 2025，任意尺度）→IQ-LUT（2026）。
   **2025–2026 仍在正会持续产出，远未饱和。**
3. **内容自适应稀疏计算**：CAMixerSR（CVPR 2024）→PCSR（ECCV 2024，像素级）→
   Pure-Pass（2025）→E2L-CAMixerSR（2026）；以及 Mamba 骨干（MambaIRv2 等）。
   **重要空档**：`sr_efficiency_2026.md` 明确指出——"在 patch 路由 + **异构模型池**
   + wall-clock 验证这个 ClassSR 式经典框架上，2025–2026 学术界几乎没有新的顶会工作"。

第四支线：AIM 2025（ICCV workshop）开始把高效 SR 从 fidelity 转向**感知质量+效率双目标**。

## 3. 核心查新表：与我们设想的最近邻（必须严格切割）

| 工作 | patch 路由 | 异构快慢级联 | 质量保证 | 留下的空白 |
|---|---|---|---|---|
| **ClassSR** CVPR'21 | ✅ 难度分类 | ⚠️ 同架构不同宽度子网 | ❌ 分类器 argmax，误分类无兜底 | 无回退；非异构；无 wall-clock 优先 |
| **ARM** ECCV'22 | ✅ edge score | ⚠️ 权重共享子网 | ⚠️ Edge-to-PSNR 表是**前验预测** | 预测错无纠正 |
| **PCSR** ECCV'24 | 像素级 | ✅ 多容量上采样头 | ❌ | 无质量兜底 |
| **ENAF** WACV'25 ⚠️最危险 | ✅ patch | ⚠️ 单网多出口 | ⚠️ tiny PSNR 估计器决定出口（最接近"质量感知路由"） | **仍是前置预测，无"输出不达标→升级重算"闭环；无形式化保证** |
| **MobiSR** MobiCom'19 | ✅ | ✅ 双模型映射异构处理器 | ⚠️ TV 难度代理，软约束 | 无学习路由、无后验证；2019 后该线沉寂 |
| **NEMO** MobiCom'20 | anchor 帧（视频） | ❌ | ✅ 相对逐帧 SR 的质量退化保证 | 视频场景，非单图 patch 级联 |
| **Palantír** MMSys'25 ⚠️危险 | ✅ patch 级 anchor 调度 | ❌ "做/不做 SR"二选一 | ⚠️ 轻量质量估计驱动调度 | 非轻/重模型级联；绑定编码器信息 |
| **LUT×NN 混合** | — | ⚠️ 仅**模块级**混合（Convolutional LUT for streaming VSR, TIP 2024） | ❌ | **"LUT 作为 patch 级快路径 + CNN 按需精修"的显式级联路由：检索未命中** |
| **speculative decoding**（LLM） | — | ✅ draft→verify 成熟 | ✅ 接受/拒绝机制 | **该范式尚未移植到 SR patch 级** |

**空白的精确表述**（四项，`sr_efficiency_2026.md` §6.2）：
1. 真正**独立异构**的快路径（LUT 或 SPAN-tiny）+ 独立重模型级联，而非同网子网/多出口；
2. **输出后验证的闭环**：先跑快路径 → 用便宜代理检查**实际输出** → 不达标才升级重算
   （speculative / draft-verify 语义）——SR 领域无人做；
3. **统计质量保证**（conformal：保证 ≥1−α 的 patch/图 PSNR 损失 ≤ ε）——完全空白；
4. LUT-as-fast-path 与上述任一结合——完全空白。

## 4. 跨领域机制到单图 SR 的映射矩阵

综合四份报告，把"复用/跳过"机制映射到单图 SR 的三个冗余轴：

| 源机制（领域） | → 空间轴（patch 间） | → 尺度轴（金字塔） | → 深度/通道轴 |
|---|---|---|---|
| anchor + MV 传播（NEMO/Palantír） | anchor patch + 自相似块匹配传播（需廉价匹配器；**限一跳防误差累积**） | 粗尺度作 anchor，细尺度按需精化 | 浅层作 anchor，深层按需追加 |
| **残差指导跳算（CIAF/codec skip）** | **bicubic 残差预测 ≈0 的 patch 跳过重网络**（最可直接落地） | 尺度间残差能量低 ⇒ 停止上探 | 通道贡献低 ⇒ 动态剪枝（本项目已证伪：CA gate 跨图 std 仅 0.019） |
| 缓存复用（DeepCache/Faster Diffusion） | 相似 patch 深层特征复用 + 浅层残差修正 | **跨尺度复用深层语义**，高分辨率只留浅层高频分支 | block 级隔块复用（本项目已证伪：前缀截断 d=9 即 −1.59 dB） |
| 时域累积 + history rejection（DLSS/FSR2） | — | 粗结果默认信任，检测"不可信区域"局部重算 | 低精度预览 + 不确定度触发全量重算 |
| 重要性→计算密度（VRS/foveated/EVASR） | patch 路由本体（信号要**近零成本**、档位要**同族函数**、**保守偏置**） | 重要区多上一层金字塔 | 重要区用更宽通道 |
| **RDO 模式决策（codec）** | **patch 级失真-计算（D-C）优化 + λ 滑杆 + 四叉树自适应 patch 划分** | 尺度选择进同一 RD 空间 | 深度/宽度档位进同一 RD 空间 |

三条来自工业界的设计准则（`video_system.md` §3.3，VRS vs SR 路由对比）：

1. **路由信号必须近零成本**（VRS 赢在注视点信号免费）。单图对应物：bicubic 前后差分
   （一次减法）、JPEG DCT 统计、下采样自一致性——**不要再训一个不小的难度网络**；
2. **档位应是"同族函数的采样密度差"而非"异族网络"**（VRS：同 shader 不同 rate），
   否则档位间输出风格不连续 → **边界伪影是 SR 路由特有问题**；
3. **保守偏置 + 显式失效清单**（文字、规则纹理、莫尔纹强制走高档），
   比追求平均最优路由更能保住质量下限。

⚠️ 注意准则 2 与空白项 1（异构级联）存在**张力**：异构模型级联在新颖性上更强，
但边界连续性风险更大。这是方案设计时必须正面处理的取舍（见 §5 方案 A 的缓解设计）。

## 5. 重构后的候选方案（3 个，按性价比排序）

### 方案 A（首选）：Draft-Verify SR —— 后验校验闭环 + conformal 质量保证

**一句话**：轻量快路径全图出草稿 → 便宜的**后验**误差检测（不是前验难度预测）
→ 少数不达标 patch 升级重模型 → conformal 校准给出"≥1−α 的图 PSNR 损失 ≤ ε"的保证。

与三份报告的对应：LLM 的 draft-verify 语义 + CALM/Fast yet Safe 的风险控制 +
codec RDO 的 λ 滑杆 + VRS 的保守偏置。

**为什么它同时占住三处空白**：异构级联（空白 1）+ 输出后验校验（空白 2）+
统计保证（空白 3）。三者中任一单独都薄，组合起来机制级新颖性高。

**关键设计点**：
- **后验 vs 前验是核心差异**：ENAF/ARM 都是"先预测难度再决定路径"；我们是
  "先算出草稿，再检测草稿的实际误差"。后验信号质量高得多（因为已经有输出可看），
  且天然对应 speculative 的 accept/reject 语义；
- **误差检测器必须极便宜**（对标 Palantír 的 <6% 预算）：候选是
  `|draft − bicubic|` 的统计量、draft 的高频能量、或一个 3 层微型 CNN；
- **边界伪影缓解**（回应 §4 准则 2 的张力）：升级重算时带 halo padding；
  相邻档位差异过大时触发局部平滑；BiLD 式回滚思想；
- **conformal 校准**：在 held-out 集上标定阈值 λ，控制"草稿被接受的 patch 相对
  重模型输出的 PSNR 差"的期望/分位数风险。

**免训练 kill-check（SG-A）**：用 CARN-M/SPAN 当快路径、RCAN 当重路径，测三件事：
① 后验信号（`|draft−bicubic|` 等）与真实 `draft_drop` 的 AUC——目标 ≥0.90
（对比手工前验特征的 0.807，本项目已测）；② 该 AUC 下 conformal 阈值能兑现的
cheap% 与实测 speedup；③ 边界伪影的定量评估。**若后验 AUC 不显著高于前验 0.807，
方案 A 的核心假设不成立。**

### 方案 B：LUT-as-Fast-Path 混合级联

**一句话**：TinyLUT/AutoLUT 当快路径（亚毫秒、极低能耗），CNN 只精修少数难 patch。

`sr_efficiency_2026.md` 确认这是**完全空白**（LUT 文献里的"级联"都是 LUT→LUT）。
优势：LUT 快路径的延迟几乎可忽略，级联的地板由 escalation 端单独决定；
且 LUT 质量显著高于 bicubic，cheap% 应远高于本项目实测的 8.5%。
风险：LUT 与 CNN 的输出风格差异更大（边界伪影风险高于同族模型）；需要跑通 LUT
推理栈（TinyLUT 有开源代码）。**可与方案 A 组合**（LUT 快路径 + 后验校验）。

### 方案 C（低风险储备）：尺度轴的 CIAF 式跳算

**一句话**：把「bicubic 上采样」视为参考帧、「HR − bicubic」视为残差，
预测残差能量低的 patch 直接采纳 bicubic——**这是 CIAF 残差跳算在尺度维的翻版**，
判据有明确物理含义（bicubic 可解释的部分不必算）。

本项目实测这条线的 oracle 上界只有 1.27×（bicubic 太弱），所以单独不够；
但如果快路径换成 LUT/SPAN，它就退化为方案 A/B 的一个特例。**保留为理论视角，
不单独立项。**

3. 方案 A 的"质量保证"是 **marginal 统计保证**（依赖可交换性假设），
   **不是 per-image 确定性保证**，也不是 bit-exact 等价——表述必须精确；
4. 与 ENAF/ARM/Palantír 的差异必须在 related work 中显式论证，不能回避；
5. 本项目已证伪的三条路线（空间窗口、前缀深度、CA 通道）应作为负结果诚实报告，
   它们是"为什么必须走 patch 级异构级联"的论证链条，而非需要隐藏的失败。

## 9. 一句话总结

> 跨领域调研给出了一个三方独立指向的机会：**把 LLM 的 draft-verify 语义
> （后验校验而非前验预测）+ conformal 风险控制（回归任务的统计质量保证）
> 移植到 SR 的 patch 级异构级联上**。这三处空白单独都薄，组合起来机制级新颖性高，
> 且与本项目已有的 RCAN 重路径、Gate 纪律、负结果证据链完全衔接。
> 下一步是一小时的免训练 kill-check：**后验误差信号的 AUC 能否显著超过
> 已实测的前验特征 0.807**。
